Import files

Kapowarr looks for comic files that aren't in your library yet, matches them to Comic Vine, and lets you fix anything it couldn't match before a file moves.

Where should Kapowarr look?

Managed volume folders are skipped. Files in root folders and unmanaged subfolders are included.

Enter a folder or pattern inside a configured root folder.

Scan options

Smaller scans finish sooner and use fewer Comic Vine lookups.

Use this only when each individual issue has its own folder.

Keep English-only on unless you want translated editions.

How matching works
  • Tagged CBZ/ZIP files are matched from the Comic Vine ID in their ComicInfo.xml first, then by title.
  • Series already in your library are checked before a new Comic Vine search.
  • Comic Vine lists standard volumes, collected editions, one-shots and hardcovers separately, so check guesses before importing.
  • Import no more than about 50 new series at once to stay under Comic Vine's rate limit.

No new comic files found

Everything in your root folders is already in your library. Check the folder selection and scan limit if you expected more.

Comic Vine API key required

Add an API key in General settings before scanning your library.
