Import an existing library

Scan organized comic folders, review the matches, then choose what to import.

Before you scan
  • Tagged CBZ/ZIP files are matched from embedded ComicInfo.xml metadata before Kapowarr falls back to the filename.
  • Volumes already in your Kapowarr library are checked before a new ComicVine search, which makes adding more issues to an existing series more reliable.
  • Review matches carefully. ComicVine lists standard volumes, collected editions, one-shots, hardcovers, and other releases separately.
  • Import in batches of no more than 50 new volumes to avoid ComicVine rate limits.
  • Files are not allowed to be directly in the root folder. They have to be in a sub-folder.
  • If each issue has a separate sub-folder, enable 'Apply limit to parent folder' so that the limit is correctly applied.

*Input has to be a folder (pattern) and all matches have to be a root folder or a sub-folder of one
